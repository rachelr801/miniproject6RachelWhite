About this project

Reading List is a small Django web app built for Mini Project 6.

Each user has their own private list of books. Books are grouped by genre and move through three statuses: Want to Read, Currently Reading, and Finished.

Built with

  • Python and Django
  • SQLite for the database
  • Bootstrap 5 for layout, cards, and modals
  • Django's built-in authentication for registration and login

Genres are managed by staff through the Django admin site.
